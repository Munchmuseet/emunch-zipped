# emunch-zipped
XML files for sharing

The zip files contain all encoded transcriptions. Most are published online at https://www.emunch.no/

The files are organised in main file (parent) plus one file per page of the object, so e.g.:
  No-MM_N0001.xml
  No-MM_N0001-01.xml
  No-MM_N0001-02.xml
  No-MM_N0001-03.xml
  No-MM_N0001-04.xml
